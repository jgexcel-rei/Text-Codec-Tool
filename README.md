# 多模式文本编码与加解密工具

一个基于 C 语言实现的简单文本编码、加密与解密工具。

## 项目简介

本项目用于对输入的字符串进行不同方式的编码、加密和解密处理，支持多种常见的文本处理方式。

通过菜单选择对应功能，并根据需要输入密钥，即可完成字符串的编码、加密或解密。

## 功能

目前支持以下功能：

- 凯撒密码
- 异或加密 / 解密
- 摩斯电码
- URL 编码
- Base64 编码
- 密钥输入
- 字符串处理

## 技术栈

- C 语言
- 字符串处理
- 字符数组
- 指针
- 位运算
- 函数封装
- 条件判断与循环
- ASCII 字符处理
